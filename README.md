# NeuroLab

Личная исследовательская лаборатория: происхождение научных утверждений рядом с небольшой воспроизводимой численной моделью. Первая версия — нативное приложение на Rust / Bevy для macOS Apple Silicon; сервер и API-ключи не нужны.

## Возможности

- Карточки кофеина, аденозина, A1 и A2A; интерактивная карта четырёх связей, выбор узлов и связей, перемещение и масштабирование.
- Объяснения, DOI/PMID, экспериментальный контекст, вид, ограничения и статус проверки аннотации для каждого утверждения.
- Отдельный **illustrative**-эксперимент с абстрактными лигандами A/B: ползунки, точный ввод, три доли, две кривые и текущая точка.
- «Ответ рецептора»: опубликованная операционная модель Black–Leff при n = 1, отдельные кривые занятости и функционального ответа, параметры x и τ, асимптота и EC50/K_A. Происхождение формул и статус проверки доступны справа.
- Сохранение/открытие версионированного JSON; воспроизведение через CLI; экспорт текущего результата и кривых в CSV/JSON.
- Офлайн-работа: каталог и кириллический шрифт встроены в бинарный файл. Интернет нужен только для первоначальной установки зависимостей и открытия внешних публикаций.

## Требования и запуск

Целевая платформа: macOS Apple Silicon, Metal, Xcode Command Line Tools (`xcode-select --install`). Rust 1.89+ с rustfmt и Clippy; фактически проверенный toolchain и ОС — в [docs/verification.md](docs/verification.md). При разрешении зависимостей сохранён `Cargo.lock`.

```sh
cd /Users/arsenysmorodin/brain-engine
cargo run -p neuro-app --locked
```

В этой рабочей копии Rust установлен изолированно в `.local/`, без изменения системного PATH. Для неё **заменяйте `cargo` на `./scripts/cargo-local`**:

```sh
./scripts/cargo-local run -p neuro-app --locked --offline
./scripts/cargo-local run -p neuro-cli --locked --offline -- run scenarios/competition.json --csv /tmp/neuro-results.csv
```

После первой сборки можно запускать `./target/debug/neuro-app` без Cargo и сети. Собрать обычный локальный `.app`: `./scripts/macos-app`; открыть `open output/NeuroLab.app`. Подпись локальная ad hoc, дистрибуция и notarization не настроены.

Используется проверенная совместимая пара Bevy **0.18.1** и bevy_egui **0.39.1**, egui **0.33.3** в lockfile. Это осознанно закреплённая поддерживаемая пара, не заявление о последних релизах. [Таблица совместимости](https://docs.rs/crate/bevy_egui/0.39.1), [Bevy features](https://docs.rs/crate/bevy/0.18.1/features). Выключены звук, PBR/3D и игровые подсистемы; сборка ограничена двумя jobs, debug symbols и incremental выключены. В обычном режиме окно реагирует на события с резервным интервалом 50 мс в фокусе и 1 с вне фокуса; результаты расчёта кешируются.

## Основной сценарий

1. Откройте карточку «Кофеин». Выберите узел или подпись/линию связи; объяснение появится справа. Связи также доступны обычными кнопками в карточке — для клавиатуры. Перетаскивайте карту; масштаб меняйте прокруткой или кнопками. «По центру» восстанавливает вид.
2. Выберите «Эксперимент A / B». Изменяйте **a = [A]своб / Kd_A** и **b = [B]своб / Kd_B**. Ползунки покрывают 0–100, точный ввод — все конечные неотрицательные f64, включая научную запись. Допустимы точка и запятая.
3. Например, `a = 3`, `b = 6`: свободно 10%, занято A 30%, занято B 60%. Это результат абстрактной модели, не оценка кофеина.
4. «Сохранить» / Cmd+S открывает диалог с редактируемым полным путём, например `/tmp/my-neuro.json`. «Открыть» / Cmd+O загружает JSON и пересчитывает его. Список JSON в выбранной папке кликабелен. Замена существующего файла обозначена явно. При ошибке предыдущий сценарий сохраняется в памяти.
5. «Экспорт CSV» сохраняет текущую точку и обе кривые. Ошибки чтения, записи, версии и ввода видны в окне/строке состояния. NaN/∞/отрицательные параметры блокируют расчёт, сохранение и экспорт.
6. Выберите «Ответ рецептора». При x = 1, τ = 10 занятость равна 50%, ответ E/E_m — 83,33%, асимптота — 90,91%. Измените τ, чтобы увидеть разницу между связыванием и ответом. Быстрые примеры τ соответствуют теоретическому примеру публикации; параметры остаются illustrative. Сохранение и CSV относятся к выбранному экрану (на карте — A/B). Открытие JSON автоматически выбирает модель; состояние другого эксперимента сохраняется в памяти.

```sh
cargo run -p neuro-cli --locked -- new /tmp/my-neuro.json
cargo run -p neuro-cli --locked -- run /tmp/my-neuro.json \
  --csv /tmp/neuro.csv --json /tmp/neuro.json
cargo run -p neuro-cli --locked -- new-response /tmp/response-scenario.json
cargo run -p neuro-cli --locked -- run scenarios/response.json --csv /tmp/response.csv
cargo run -p neuro-cli --locked -- benchmark-response
```

`run` выводит полный JSON-результат в stdout; ошибки — в stderr с exit code 1. CSV имеет `row_type=current` и `row_type=curve`, версии модели, отметку illustrative, входы, три доли и сравнение `p_a_without_b`. Десятичный разделитель — точка. Формат f64 обеспечивает round trip; сумма отображённых округлённых процентов может отличаться от 100%.

`run` выбирает модель по `model_id`. Для `operational_agonism_n1_v1` CSV содержит x, τ, занятость, E/E_m, асимптоту и EC50/K_A; при τ = 0 последнее поле пустое (JSON: null). Формулы, источник, численная устойчивость и границы эталона: [docs/response-model.md](docs/response-model.md). Проверка теоретических кривых не является независимой экспериментальной валидацией.

## Проверки

```sh
cargo fmt --all --check
cargo test --workspace --locked --offline
cargo clippy --workspace --all-targets --locked --offline -- -D warnings
cargo build --workspace --locked --offline
cargo run -p neuro-app --locked --offline -- --smoke-test output/smoke
cargo run -p neuro-cli --locked --offline -- run output/smoke/scenario.json --csv output/smoke/cli.csv
cmp output/smoke/gui.csv output/smoke/cli.csv
cargo run -p neuro-cli --locked --offline -- run output/smoke/response.json --csv output/smoke/response-cli.csv
cmp output/smoke/response-gui.csv output/smoke/response-cli.csv
```

GUI smoke требует графического сеанса и Metal, открывает окно, снимает карту/источник/эксперимент/ошибку, сохраняет и перечитывает сценарий, экспортирует CSV и завершает работу. Это программная проверка пути приложения; фактическая проверка мыши и клавиатуры описана отдельно в [протоколе](docs/verification.md). `cargo test` без `--workspace` по умолчанию не собирает Bevy.

## Ограничения

Один рецептор и один сайт, заданные свободные концентрации, равновесие. A/B вычисляет только занятость. Отдельный модуль Black–Leff вычисляет нормированный ответ абстрактной системы; независимая экспериментальная валидация не выполнена. Нет кинетики, фармакокинетики, дозировок, персональных или клинических прогнозов. Числа демонстраций не измерены для кофеина. A1/A2A не объединяются. Карта не исчерпывает мишени веществ.

Для карты проверены аннотации трёх первичных публикаций; их полный текст не объявляется проверенным. Для операционной модели проверен полный открытый текст Jakubík et al. (2019). Количественные Kd реальных веществ отсутствуют, не заменяются Ki/IC50/EC50. Доступ к внешнему сайту публикации может требовать сети/подписки. Данные обновляются вручную и встроены при сборке.

Первая версия использует ясную 2D-схему, без мозга и раскраски активности. 3D отложен до наличия научно полезного представления. Диалог файлов встроен в приложение, не является Finder. Размер окна — минимум 1100×720; закрытие окна не сохраняет изменения автоматически, несохранённое состояние обозначается внизу. Пакет для распространения не подписан Developer ID.
