# NeuroLab

Среда моделирования мозга с интерактивной 3D-анатомией, динамикой нейронных популяций и воспроизводимыми численными модулями. Нативное приложение на Rust / Bevy для macOS Apple Silicon; сервер и API-ключи не нужны.

## Возможности

- Объёмный мозг из официального BodyParts3D: 58 именованных структур, 63 меша, кора с извилинами, внутренние структуры, мозжечок, ствол, белое вещество и желудочки.
- Вращение, приближение, панорамирование, выбор по реальной поверхности или списку, поиск, анатомические слои, полушария, раздвижение и изоляция области. Цвета показывают анатомические группы.
- Сохранение сцены: камера, выбор, видимость и цветовая схема. FMA ID и отдельные объекты геометрии подготовлены для дальнейшего подключения моделей популяций и связей.
- Сетевая симуляция Wilson–Cowan: 47 областей серого вещества, 94 возбуждающих/тормозных популяции, 46 направленных связей с весами и задержками. Стартовая связность и параметры демонстрационные, не измеренный коннектом.
- Запуск, пауза, шаг, сброс, стимуляция выбранной области, фиксированная шкала E на 3D-мозге, график E/I и просмотр истории. Редактирование популяций и связей, сохранение проекта, повторный расчёт через CLI, CSV всей вычисленной трассы.
- «Кофеин · PK и мозг»: повторные пероральные приёмы, редактируемые параметры, плазма, условное место эффекта Ce, графики и баланс массы до 48 часов. Интерактивный путь вещества с источниками, отдельные PET-оценки A1/A2A на 3D-мозге и включаемая гипотеза влияния на E/I.
- Карточки кофеина, аденозина, A1 и A2A; интерактивная карта четырёх связей, выбор узлов и связей, перемещение и масштабирование.
- Объяснения, DOI/PMID, экспериментальный контекст, вид, ограничения и статус проверки аннотации для каждого утверждения.
- Отдельный **illustrative**-эксперимент с абстрактными лигандами A/B: ползунки, точный ввод, три доли, две кривые и текущая точка.
- «Ответ рецептора»: опубликованная операционная модель Black–Leff при n = 1, отдельные кривые занятости и функционального ответа, параметры x и τ, асимптота и EC50/K_A. Происхождение формул и статус проверки доступны справа.
- Сохранение/открытие версионированного JSON; воспроизведение через CLI; экспорт текущего результата и кривых в CSV/JSON.
- Офлайн-работа: мозг, метаданные, каталоги и шрифты встроены в бинарный файл. Интернет нужен для первоначальной установки зависимостей, повторного импорта исходных данных и внешних ссылок.

## Требования и запуск

Целевая платформа: macOS Apple Silicon, Metal, Xcode Command Line Tools (`xcode-select --install`). Rust 1.89+ с rustfmt и Clippy; фактически проверенный toolchain и ОС — в [docs/verification.md](docs/verification.md). При разрешении зависимостей сохранён `Cargo.lock`.

```sh
cd /Users/arsenysmorodin/brain-engine
cargo run -p neuro-app --locked
```

В этой рабочей копии Rust установлен изолированно в `.local/`, без изменения системного PATH. Для неё **заменяйте `cargo` на `./scripts/cargo-local`**:

```sh
./scripts/cargo-local run -p neuro-app --locked --offline
./scripts/cargo-local run -p neuro-cli --locked --offline -- run scenarios/competition.json --csv /tmp/neuro-results.csv
```

После первой сборки можно запускать `./target/debug/neuro-app` без Cargo и сети. Собрать обычный локальный `.app`: `./scripts/macos-app`; открыть `open output/NeuroLab.app`. Подпись локальная ad hoc, дистрибуция и notarization не настроены.

Используется Bevy **0.18.1** и bevy_egui **0.39.1**, egui **0.33.3** в lockfile. [Таблица совместимости](https://docs.rs/crate/bevy_egui/0.39.1), [Bevy features](https://docs.rs/crate/bevy/0.18.1/features). Для мозга включён PBR; звук и ненужные игровые подсистемы выключены. Сборка ограничена двумя jobs, debug symbols и incremental выключены. 3D рисуется в отдельную текстуру с длинной стороной до 1600 пикселей, включая Retina; при переходе в другие разделы 3D-камера выключается. MSAA и карты теней не используются. В обычном режиме окно реагирует на события с резервным интервалом 50 мс в фокусе и 1 с вне фокуса; численные результаты кешируются.

## Работа с мозгом

1. При запуске открывается «Мозг · 3D». Вращайте перетаскиванием, приближайте прокруткой или кнопками −/+, перемещайте правой кнопкой. Кнопки ракурсов и «По центру» восстанавливают удобный вид.
2. Нажмите на поверхность или найдите область в списке по русскому/английскому имени или FMA ID. Справа появятся её название, группа, сторона и источник.
3. «Внутренние структуры» скрывает кору и открывает глубокие отделы. Слои, выбор полушария и раздвижение дают другие способы исследования. «Оставить только выбранную» изолирует структуру; «Приблизить» наводит камеру. Геометрия при раздвижении только перемещается для обзора.
4. «Сохранить» записывает JSON сцены; «Открыть» восстанавливает его. Пример: `scenes/brain.json`. CSV на этом экране — инвентарь областей, без выдуманных значений активности.

```sh
./scripts/cargo-local run -p neuro-cli --locked --offline -- atlas --csv /tmp/brain-regions.csv
```

Динамика и связи хранятся отдельно от анатомии и обращаются к областям по FMA ID. Визуальная анатомия не задаёт автоматически функциональные сети. Источник, лицензия, преобразование координат и путь импорта: [docs/brain-atlas.md](docs/brain-atlas.md).

## Запуск симуляции мозга

1. На экране мозга выберите «Симуляция» и нажмите «Запуск». Через 50 модельных мс начнётся импульс в левой затылочной доле; активность пройдёт по демонстрационным ветвям и затухнет. По умолчанию 100 модельных мс воспроизводятся примерно за секунду, dt остаётся 0.25 мс.
2. Цвет поверхности показывает вычисленную E-активность по фиксированной шкале 0–1. Серый — область без модели. Выберите область, чтобы увидеть её E/I, график и входящие/исходящие связи со стрелками. Клик по графику возвращает к записанному кадру; будущие точки не дорисовываются.
3. «Пауза», «Шаг 2 мс», «Сброс» и скорость управляют расчётом. «Импульс в выбранную» заменяет протокол и перезапускает его в этой области с t=0. Во внутренних структурах можно наблюдать глубокие отделы. Скрытие геометрии не отключает область из сети.
4. В инспекторе доступны локальные E/I-параметры, веса, задержки, отключение, удаление и добавление направленной связи. Изменение сбрасывает расчёт и ставит его на паузу. Неверные значения блокируют запуск и экспорт; прежняя активность не подставляется.
5. «Сохранить» в режиме симуляции пишет проект `neuro-brain-project.json`: сцена, сеть и протокол. Открытие восстанавливает их с t=0 на паузе. «Экспорт CSV» пишет всю уже вычисленную трассу в `neuro-brain-trace.csv`, включая отсчёты после просматриваемого кадра истории. В режиме анатомии сохраняется прежний формат сцены и экспортируется инвентарь.

```sh
./scripts/cargo-local run -p neuro-cli --locked --offline -- new-network /tmp/network.json
./scripts/cargo-local run -p neuro-cli --locked --offline -- simulate scenarios/brain-network.json --csv /tmp/brain-trace.csv --json /tmp/brain-trace.json
# Сохранённый GUI-проект воспроизводится тем же вычислительным ядром:
./scripts/cargo-local run -p neuro-cli --locked --offline -- simulate neuro-brain-project.json --csv /tmp/replayed-brain.csv
```

Уравнения, источники, единицы, задержки, проверка шага и ограничения: [docs/network-model.md](docs/network-model.md). E/I — нормированная активность модели, не Гц или BOLD. Области без популяций остаются неизвестными. Ни геометрия, ни движение полушарий не определяют проводимость, вес или задержку.

## Основной сценарий

1. Через «Другие разделы» откройте «Карта механизмов» и карточку «Кофеин». Выберите узел или подпись/линию связи; объяснение появится справа. Связи также доступны обычными кнопками в карточке — для клавиатуры. Перетаскивайте карту; масштаб меняйте прокруткой или кнопками. «По центру» восстанавливает вид.
2. Выберите «Эксперимент A / B». Изменяйте **a = [A]своб / Kd_A** и **b = [B]своб / Kd_B**. Ползунки покрывают 0–100, точный ввод — все конечные неотрицательные f64, включая научную запись. Допустимы точка и запятая.
3. Например, `a = 3`, `b = 6`: свободно 10%, занято A 30%, занято B 60%. Это результат абстрактной модели, не оценка кофеина.
4. «Сохранить» / Cmd+S открывает диалог с редактируемым полным путём, например `/tmp/my-neuro.json`. «Открыть» / Cmd+O загружает JSON и пересчитывает его. Список JSON в выбранной папке кликабелен. Замена существующего файла обозначена явно. При ошибке предыдущий сценарий сохраняется в памяти.
5. «Экспорт CSV» сохраняет текущую точку и обе кривые. Ошибки чтения, записи, версии и ввода видны в окне/строке состояния. NaN/∞/отрицательные параметры блокируют расчёт, сохранение и экспорт.
6. Выберите «Ответ рецептора». При x = 1, τ = 10 занятость равна 50%, ответ E/E_m — 83,33%, асимптота — 90,91%. Измените τ, чтобы увидеть разницу между связыванием и ответом. Быстрые примеры τ соответствуют теоретическому примеру публикации; параметры остаются illustrative. Сохранение и CSV относятся к выбранному экрану (на карте — A/B). Открытие JSON автоматически выбирает сцену или модель; другие разделы сохраняются в памяти.

```sh
cargo run -p neuro-cli --locked -- new /tmp/my-neuro.json
cargo run -p neuro-cli --locked -- run /tmp/my-neuro.json \
  --csv /tmp/neuro.csv --json /tmp/neuro.json
cargo run -p neuro-cli --locked -- new-response /tmp/response-scenario.json
cargo run -p neuro-cli --locked -- run scenarios/response.json --csv /tmp/response.csv
cargo run -p neuro-cli --locked -- benchmark-response
```

`run` выводит полный JSON-результат в stdout; ошибки — в stderr с exit code 1. CSV имеет `row_type=current` и `row_type=curve`, версии модели, отметку illustrative, входы, три доли и сравнение `p_a_without_b`. Десятичный разделитель — точка. Формат f64 обеспечивает round trip; сумма отображённых округлённых процентов может отличаться от 100%.

`run` выбирает модель по `model_id`. Для `operational_agonism_n1_v1` CSV содержит x, τ, занятость, E/E_m, асимптоту и EC50/K_A; при τ = 0 последнее поле пустое (JSON: null). Формулы, источник, численная устойчивость и границы эталона: [docs/response-model.md](docs/response-model.md). Проверка теоретических кривых не является независимой экспериментальной валидацией.

## Кофеин: от приёма к мозгу

1. Выберите «Кофеин · PK и мозг» слева или вкладку «Кофеин» над мозгом. Начальный пример — 100 мг в момент 0; параметры сравнительные.
2. В «Протоколе» изменяйте дозы, время (минуты с шагом 0.5), массу, Vd, F и полувремена. «Добавить приём» позволяет исследовать накопление, «Без кофеина» даёт нулевой контроль. Изменения пересчитывают PK и ставят воспроизведение на паузу. Панель протокола прокручивается.
3. «Запуск», «+15 мин», ползунок времени и щелчок по графику выбирают состояние PK. Вся кривая рассчитана заранее общим интегратором GUI/CLI.
4. «Путь вещества» открывает карту из 11 узлов и 12 связей. Узлы и связи выбираются; карта перемещается и масштабируется. В 3D доступны местная Ct, CBF, доставка, бассейны, A1, A2A, общий Ce и ΔE. Чтобы рассмотреть внутренние структуры, уменьшите «Плотность ткани»; без артерий доступна кнопка «Стриатум». Серый означает отсутствие количественной оценки. Переключатель «График» освобождает место для крупной визуализации; при переходе к пути вещества график изначально скрывается.
5. Для сравнения популяций включите «Гипотеза связи с E/I» справа и нажмите «Сравнить E/I при этом времени». Коэффициенты и выбор текущей сети находятся в протоколе. График показывает два одинаковых нейронных опыта с/без добавочного входа кофеина; его время — миллисекунды. Изменение PK или времени аннулирует снимок.
6. «Сохранить» записывает сцену, PK и сеть гипотезы. Открытие возвращает время PK к 0 на паузе. «Экспорт CSV» записывает всю PK-трассу. Полный отчёт и нейронное сравнение воспроизводятся CLI.

```sh
./scripts/cargo-local run -p neuro-cli --locked --offline -- new-caffeine /tmp/caffeine.json
./scripts/cargo-local run -p neuro-cli --locked --offline -- caffeine scenarios/caffeine.json --csv /tmp/caffeine-pk.csv --json /tmp/caffeine-report.json
# Для проекта с явно включённой гипотезой:
target/debug/neuro-cli caffeine neuro-caffeine-project.json --network-at-min 60 --json /tmp/caffeine-neural.json
```

[Уравнения, единицы и источники](docs/caffeine-model.md). A1 — общая PET-оценка, A2A — стриатальная модель из небольшой PD-когорты. Занятость рецептора не равна активации или проценту бодрости. Ce и переход к E/I — допущения; региональная Ct и её связь с E/I — допущения. Региональная перфузия описана [отдельно](docs/perfusion-model.md). Индивидуальной калибровки нет.

## Сосуды и региональная доставка

Новый протокол кофеина включает перфузию 54 неполостных структур. Артериальная геометрия BodyParts3D: **85 именованных структур и ветвей, 127 мешей**, в исходном пространстве мозга. Геометрия вен и капилляров не включена.

1. «Кофеин» → «Настройки» → «Кровоснабжение». Запустите время или введите минуты числом. Для первых минут выберите скорость 0.05/0.5 мин/с; запись идёт каждые 3 с до 5 мин, затем каждые 30 с.
2. Снизьте «Плотность ткани», вращайте сцену. Артерию можно выбрать на полупрозрачном мозге или в списке. Серые соединительные сосуды не имеют рассчитанного коллатерального перетока. При показе артерий полушария остаются сомкнутыми.
3. Выберите участок ткани (при необходимости через «Области»). Слева доступны CBF₀, множитель потока, задержка, масса, Kp и приблизительный бассейн. «Поток ×0.3» — иллюстративная проверка меньшей доставки. Это не клиническая модель ишемии.
4. В слое 3D выберите местную концентрацию, кровоток, доставку или бассейны. У ткани и артерий отдельные шкалы. «График» открывает Ct/Ca, CBF с/без сосудистого ответа, приток/отток. До 5 мин график увеличивает начало; «Полный горизонт» возвращает сутки.
5. Включите гипотезу E/I и нажмите «Сравнить E/I при этом времени». Входы используют местную Ct. Нейронный опыт имеет отдельную миллисекундную ось; перемещение PK-кадра аннулирует сравнение.
6. JSON проекта включает региональные параметры. «Экспорт CSV» предлагает общую PK или региональный кровоток и доставку. Старые проекты без `perfusion` сохраняют общий Ce; расширение включается явно.

```sh
./scripts/cargo-local run -p neuro-cli --locked --offline -- caffeine scenarios/caffeine-perfusion.json --regional-csv /tmp/caffeine-regions.csv --csv /tmp/caffeine-pk.csv --json /tmp/caffeine-perfusion.json
```

Артериальная Ca задаётся общей PK; венозный возврат на неё не влияет. Локальные количества — диагностические, их нельзя прибавлять к системной массе. CBF₀, масса, транзит, Kp и концентрационный ответ пока иллюстративны. [Уравнения, единицы, первичные источники и границы](docs/perfusion-model.md).

## Проверки

```sh
cargo fmt --all --check
cargo test --workspace --locked --offline
cargo clippy --workspace --all-targets --locked --offline -- -D warnings
cargo build --workspace --locked --offline
cargo run -p neuro-app --locked --offline -- --smoke-test output/smoke
cargo run -p neuro-cli --locked --offline -- run output/smoke/scenario.json --csv output/smoke/cli.csv
cmp output/smoke/gui.csv output/smoke/cli.csv
cargo run -p neuro-cli --locked --offline -- run output/smoke/response.json --csv output/smoke/response-cli.csv
cmp output/smoke/response-gui.csv output/smoke/response-cli.csv
cargo run -p neuro-cli --locked --offline -- atlas --csv output/smoke/brain-cli.csv
cmp output/smoke/brain-regions.csv output/smoke/brain-cli.csv
cargo run -p neuro-cli --locked --offline -- simulate output/smoke/brain-project.json --csv output/smoke/network-cli.csv > output/smoke/network-cli.json
cmp output/smoke/network-gui.csv output/smoke/network-cli.csv
```

GUI smoke требует графического сеанса и Metal, открывает окно, снимает мозг, внутренние и изолированные структуры, карту и численные модули; проверяет выбор треугольника, сохранение/восстановление сцены, сценарии, ошибки и CSV, затем завершает работу. Это программная проверка пути приложения; фактическая проверка мыши и клавиатуры описана отдельно в [протоколе](docs/verification.md). `cargo test` без `--workspace` по умолчанию не собирает Bevy.

## Структура

| Crate | Назначение |
|---|---|
| neuro-domain | Каталог, происхождение утверждений, сценарии, валидация и атомарная запись |

## Ограничения

Один рецептор и один сайт, заданные свободные концентрации, равновесие. A/B вычисляет только занятость. Отдельный модуль Black–Leff вычисляет нормированный ответ абстрактной системы; независимая экспериментальная валидация не выполнена. A/B и Black–Leff не включают фармакокинетику или дозы; отдельный модуль кофеина рассчитывает PK и эмпирические PET-оценки. Персональных или клинических прогнозов нет. Числа абстрактных демонстраций не измерены для кофеина. A1/A2A не объединяются. Карта не исчерпывает мишени веществ.

Кофеин: региональный кровоток и общая Ct рассчитываются по редактируемым допущениям. Нет свободной тканевой концентрации, количественной кинетики метаболитов, толерантности и динамики аденозина. Начальные параметры не подогнаны к одному человеку. Применение PET-функций к изменяющейся PK квазиравновесное; A2A получена у пяти пациентов с болезнью Паркинсона. Гипотеза E/I не валидирована физиологически.

Для карты проверены аннотации трёх первичных публикаций; их полный текст не объявляется проверенным. Для операционной модели проверен полный открытый текст Jakubík et al. (2019). Количественные Kd реальных веществ отсутствуют, не заменяются Ki/IC50/EC50. Доступ к внешнему сайту публикации может требовать сети/подписки. Данные обновляются вручную и встроены при сборке.

Анатомия основана на низкополигональной модели взрослого мужчины BodyParts3D, CC BY 4.0: набор неполон, индивидуальная анатомия и MNI-регистрация не представлены. В анатомии цвета категориальные, в симуляции — вычисленная E-активность. Связность, локальные параметры, стимулы и задержки стартовой сети — допущения. Физиологической валидации сети нет; мозжечок, ствол, белое вещество и полости не моделируются. Диалог файлов встроен в приложение, не является Finder. Размер окна — минимум 1100×720; закрытие окна не сохраняет изменения автоматически, несохранённое состояние обозначается внизу. Пакет для распространения не подписан Developer ID.
