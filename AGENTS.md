# NeuroLab

- Весь прикладной и научный код — Rust. Bevy/bevy_egui только в neuro-app.
- neuro-engine не зависит от GUI; GUI и CLI используют один путь evaluate.
- Научные утверждения требуют источника, контекста, вида, ограничений и честного статуса проверки. Неизвестное не равно нулю.
- Реальные вещества отделены от illustrative-параметров. Занятость рецепторов не является моделью активации, поведения или клинической безопасности.
- Изменения формулы требуют аналитических и численных тестов, версии модели и обновления docs/model.md. Сохранять Cargo.lock.
- Перед завершением: cargo fmt --all --check; cargo test --workspace --locked; cargo clippy --workspace --all-targets --locked -- -D warnings; cargo build --workspace --locked. Визуальную проверку проводить отдельно от сборки.
- Беречь ресурсы: не повышать jobs выше 2 без необходимости, не включать ненужные Bevy features.
- После каждого значимого изменения выполнить подходящую проверку и сделать отдельный коммит. Не отправлять изменения в remote без необходимости или запроса пользователя.
