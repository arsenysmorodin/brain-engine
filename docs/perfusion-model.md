# Региональная доставка кофеина

Модель `caffeine_regional_perfusion_v1`, revision 1, provenance `perfusion_sources_2026_10_24_v1`. Необязательное расширение `perfusion` сценария кофеина. Отсутствующее поле сохраняет прежнюю модель с общим условным Ce. Новые сценарии включают региональную перфузию. Все параметры сохраняются в проекте; GUI и CLI используют один CPU/f64 расчёт.

## Граница и баланс

Это односторонний эксперимент с заданной артериальной концентрацией: аналитическое решение той же пероральной модели Cp(t), с индивидуальной задержкой tau. Предполагается кровь/плазма = 1. Региональные количества диагностические; **их нельзя прибавлять к systemic_mg**. Обратная связь венозного возврата в общую PK не моделируется. Это не новая модель полного распределения вещества по организму.

Для каждого неполостного участка:

```
Ca_r(t) = Cp(t - transit_sec_r / 60)
V_r [л] = tissue_mass_g_r / 1000       (принято 1 г/мл)
CBF_r = CBF0_r * flow_fraction_r * (1 - Rmax * Ca_r/(C50_flow + Ca_r))
Q_r [л/мин] = CBF_r [мл/(100 г·мин)] * tissue_mass_g_r / 100000
Ct_r = M_r / V_r
Cv_r = Ct_r / Kp_r
dM_r/dt = Q_r * (Ca_r - Cv_r)
Jin_r = Q_r * Ca_r; Jout_r = Q_r * Cv_r
M_r(t) = integral Jin - integral Jout
```

Выключенная сосудистая гипотеза убирает множитель снижения. Нулевой `flow_fraction` полностью прекращает обмен и сохраняет ранее накопленную массу: это технический контроль доставки, не модель ишемии/гибели ткани. Не рассчитываются давление, сопротивление, диаметр, коллатеральный переток, кислород, BBB-проницаемость или отдельные венозные компартменты. Локальный отток — граница well-stirred участка.

Численный метод: экспоненциальное обновление линейного участка при входе/потоке в середине шага 0.025 мин (1.5 с). При постоянных входе/потоке обновление точно и сохраняет положительность. Накопленные вход/выход согласованы с изменением M. Запись каждые 0.05 мин первые 5 мин, далее 0.5 мин; общая PK при расширении записывается на той же сетке. Время в каждом отсчёте экспортируется явно.

## Значения по умолчанию и источник чисел

Все региональные параметры ниже — **иллюстративные допущения разработчика**, а не измерения данного мозга и не фит:

- Суммарные 1400 г распределены поровну по неполостным структурам атласа; это намеренно простая редактируемая схема, не оценка массы извилин по мешу.
- CBF0 = 50 мл/(100 г·мин), белое вещество 20. Внутри серого вещества одинаковый CBF0; неизвестные различия не выдуманы.
- Kp = 1, транзит 2 с, множитель потока = 1.
- Rmax = 0.4 и C50_flow = 3 мг/л — некалиброванная концентрационная гипотеза. Эти параметры не заимствованы из PET A1/A2A. Эксперименты подтверждают направление снижения CBF, но не эту функцию и не её региональные коэффициенты.
- Метка ACA/MCA/PCA/вертебробазилярного бассейна — приблизительное доминирующее снабжение всей структуры. На границах и в глубоких структурах снабжение смешанное. Доли и воксельная регистрация не заданы. Смена метки перераспределяет сводный поток по бассейнам, а не изменяет Ct автоматически.

Основные первичные источники:

- [Vidyasagar et al. 2013](https://pmc.ncbi.nlm.nih.gov/articles/PMC3677118/), DOI 10.1038/jcbfm.2013.40: 20 здоровых мужчин, 184 мг, ASL до и через 2 ч; среднее снижение серого CBF 20%, региональные статистические кластеры. Кластеры не дают отдельной скорости доставки для каждой структуры нашего атласа. Полный индексированный текст проверен 24.10.2026.
- [Perthen et al. 2008](https://pubmed.ncbi.nlm.nih.gov/18191583/), DOI 10.1016/j.neuroimage.2007.10.049: 10 регулярных потребителей, 200 мг, зрительный ROI. CBF снизился на 34.5%, изменение CMRO2 не было значимым. **Кровоток не равен нейронной активности.** Проверена аннотация.
- [Gaohua et al. 2023](https://www.mdpi.com/1422-0067/24/22/16224), DOI 10.3390/ijms242216224, Eq. 1: стандартный perfusion-limited баланс ткани; наш неэлиминирующий частный случай задаёт BP=1, CLint=0. Это источник формы уравнения, не экспериментальная валидация кофеина в мозге. Проверен индексированный полный текст/PDF.

## Связь с популяциями

При явном включении прежней гипотезы E/I вход региона использует **его Ct** на выбранном PK-снимке; без расширения — прежний общий Ce. Применение PET-функций, рассчитанных для общей плазмы, к Ct остаётся непроверенной гипотезой. Поток не превращается напрямую в E. Нет обратной нейроваскулярной связи. Сравниваются два одинаковых миллисекундных протокола сети с/без дополнительного входа; сутки PK не становятся сутками нейронного расчёта.

Проверки: точный экспоненциальный оракул при постоянном входе, равновесие/вымывание, нулевой поток, задержка и причинность, нулевая доза, региональное снижение потока, включение/отключение сосудистого ответа, локальный баланс, сравнение шага 0.025 с 0.0125 мин, совместимость старого сценария без расширения. Это численная проверка модели, а не её биологическая валидация.
