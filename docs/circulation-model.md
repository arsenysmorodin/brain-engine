# Замкнутый контур трёх пуринов

Модель `purine_closed_circulation_v1`, revision 1. CPU/f64, GUI и CLI вызывают `simulate_circulation`. Предыдущие `caffeine_oral_pk_pet_v1` и `caffeine_regional_perfusion_v1` сохранены без замены формул.

## Что является данными

Источники и статусы проверки: `data/purine-model.json`, проверено 2026-10-24. Mondal 2022: пероральный метиллиберин, взаимодействие с кофеином; He 2017: теакрин и кофеин; Wang 2020: непосредственно C150+M100+T50 мг в плазме 12 участников. Полный текст Wang не проверен, поэтому тройная модель не объявляется подгонкой его данных. Модель не объединяет измерения слюны с плазменными параметрами. Исследования малые, часть финансируется индустрией.

Начальные V/F и CL/F: M 303 л, 149 л/ч (геометрические средние Mondal, таблица 2), T 51 л, 1.6 л/ч (арифметические средние He, таблица 1). Кофеин: прежний условный ориентир V=49 л, t½=5 ч, CL=ln(2)V/5. Полувремя всасывания M/T=10 мин — допущение, не опубликованный Tmax; t½ всасывания не равен Tmax. Нет единой совместной подгонки Cmax, Tmax, AUC и полувремени; отношение средних V/CL не обязано воспроизводить среднее опубликованное t½.

Абсолютная F новых веществ неизвестна: F=1 задаёт условную шкалу массы, а не доказанную биодоступность. Количества в мг и баланс — величины этой модели. V/F не является анатомическим объёмом крови. Параметры нельзя использовать как персональный прогноз.

## Компартменты и уравнения

Для каждого вещества есть G (ЖКТ), R (остаточное кажущееся распределение организма), E (устранённое исходное вещество), и для каждой из 54 областей — C (капиллярная масса), T (тканевая), W (венозная).

Объём ткани Vt=масса/1000 л; Vc=0.03Vt и Vv=0.04Vt по умолчанию. Масса мозга 1400 г поровну по областям — предположение. Остаточный объём Vr=Vapp−Σ(KpVt+Vc+Vv), чтобы не учитывать ёмкость мозга дважды. Никакого добавления диагностической массы старой односторонней модели к новой нет. Kp=1 и обмен 0.5 мин⁻¹ по умолчанию — предположения для всех трёх веществ, особенно M/T. Реальной региональной PK M/T человека нет.

При cp=R/Vr, cc=C/Vc, ct=T/Vt, cv=W/Vv, PS=kexchange·Vt:

```
dG/dt = −ka·G
 dR/dt = ka·G − CL·cp/60 − ΣQ·cp + ΣQ·cv
 dC/dt = Q(cp−cc) − PS(cc−ct/Kp)
 dT/dt = PS(cc−ct/Kp)
 dW/dt = Q(cc−cv)
 dE/dt = CL·cp/60
```

Q=CBF·масса/100000 л/мин. Общий для трёх веществ кровоток зависит только от кофеина по прежней **некалиброванной** сосудистой гипотезе; её можно отключить. Локальные множители Q сохраняются. Старый transit_sec и региональный partition_tissue_blood из вложенного референса перфузии в этой модели **не используются**: задержку создают конечные сосудистые объёмы, Kp задаётся отдельно для каждого вещества. Сосудистый референс включает эти поля ради явного происхождения, UI не показывает их как активные параметры новой модели.

G+R+Σ(C+T+W)+E=введённая доза для каждого вещества. Для области C+T+W=кумулятивный вход−кумулятивный возврат. Возврат действительно прибавляется в R и может снова попасть в мозг; кумулятивный проход не равен уникальной дозе. E — удаление исходного вещества, не количество метаболитов/мочи. Нет отдельной модели печени, сердца, кислорода, артериального давления или пульса.

Численное решение: положительные точные попарные переносы и обратимый обмен, симметричная композиция Strang, dt=0.005 мин. Для концентрационно-зависимого Q — предиктор середины шага. Ранние кадры каждые 0.05 мин до 5 мин, затем 0.5 мин. Дозы на сетке 0.5 мин вводятся до записи кадра, включая последнюю точку. AUC интегрируется трапециями на вычислительной сетке. at выбирает ближайший записанный кадр. Тесты сравнивают шаг 0.0025, точное равновесие/сохранение обмена и аналитический Bateman при Q=0.

## Взаимодействия

По умолчанию включён **феноменологический профиль**, а не кинетика CYP1A2. При C+M CL кофеина умножается на 0.42, V/F и CL/F M — на 0.81. При C+T V/F T умножается на 35.4/51, CL/F — на 1.2/1.6. Это не установка F>1. Для тройной смеси применяется сочетание этих парных отношений; оно явно обозначено гипотезой. Нет подтверждённого правила M→T. Отключение профиля позволяет сравнить независимую PK.

Профиль применяется только к единственному одновременному приёму в t=0 каждого присутствующего вещества. При разнесённых или повторных приёмах он автоматически не применяется: исследование не даёт зависимости во времени. Изменение доз относительно опубликованных C150/M100/T125 и T50 в тройном исследовании остаётся экстраполяцией, об этом сообщает UI. Не переносим IC50 CYP1A2 в Ki. Santillo 2026 — in vitro/in silico; функциональный A2A-ответ при 100 мкМ не даёт кривую PET-занятости. Для M/T количественное нейронное действие неизвестно; отсутствие кривой не означает нулевой эффект.

## Визуализация и учебник

Дизайн продолжает native NeuroLab: Noto Sans, фон #11151C, поверхности #171D26, границы #313D4B. Кофеин #FFB252, метиллиберин #65DAC9, теакрин #B9A1F4. Слева состав/протокол, в центре анатомия и направления переноса, справа выбранная область и измеримые величины модели. Графики и баланс под мозгом, легенда всегда рядом. Цвет ткани/сосудов отображает концентрацию выбранного вещества; все три кривые можно сравнивать одновременно. Комбинированный цвет не подменяет неизвестный суммарный биологический эффект.

Схема:

```
протокол |         3D-мозг                | область
дозы     | артерии → капилляры → вены     | cc / ct / cv
обмен    |         графики трёх веществ   | Q и возврат
источники|         баланс массы           | ограничения
```

Проверка плана: вместо ещё одной панели числовых карточек центральным объектом остаётся мозг с направленным контуром. Постоянные цвета обозначают вещества, а форма/переключатели — стадии сосудистой сети; концентрация получает отдельную шкалу. Топология вен опирается на анатомическую литературу, координаты созданы в проекте. Капилляры — репрезентативные петли, не микроскопическая реконструкция; диаметр увеличен, число трубок не число человеческих капилляров. Частицы — указатели направления, их скорость не скорость крови. Артерии BodyParts3D остаются исходной анатомией с атрибуцией.

Метки направления используют отдельный визуальный ход времени (0.35 прохода пути/с), который движется только при воспроизведении в фокусе и замирает на паузе. Он не зависит от дискретного шага записанной PK и не обозначает реальную скорость крови. Это предотвращает визуальное застывание меток при выборе поздних кадров через 0.5 мин. Схематический отток мозжечка направлен к поперечным синусам/стоку, глубоких надмозжечковых областей — к большой вене мозга и прямому синусу.
