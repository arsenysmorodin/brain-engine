# Кофеин: PK, PET и экспериментальная связь с популяциями

Модель `caffeine_oral_pk_pet_v1`, ревизия 1; источники `caffeine_sources_2026_10_24_v1`. Все вычисления CPU/f64 в neuro-engine. Приложение и CLI используют один расчёт. Это исследовательский сценарий для взрослого человека, без индивидуальной калибровки и без расчёта безопасной дозы.

## Фармакокинетика

Пероральные события заданы временем в минутах и массой кофеина в мг. Напитки не переводятся в «чашки». Нулевые начальные условия; фоновая концентрация до начала сценария не задана. Одновременные и повторные приёмы суммируются.

Состояния: G — кофеин в ЖКТ, A — системная масса исходного вещества, E — накопленная элиминация исходного вещества, L — неусвоенная масса (все мг); Ce — условная концентрация места эффекта (мг/л); Q — интеграл общей концентрации плазмы (мг·мин/л).

```
G(t_dose+) = G(t_dose−) + dose
V = mass_kg · Vd_l_kg                    [л, кажущийся объём]
ka = ln(2) / absorption_half_min          [1/мин]
ke = ln(2) / (60 · elimination_half_h)    [1/мин]
kb = ln(2) / brain_equilibration_half_min [1/мин]
Cp = A / V                               [мг/л общей плазмы]
dG/dt = −ka·G
dA/dt = F·ka·G − ke·A
dE/dt = ke·A
dL/dt = (1−F)·ka·G
dCe/dt = kb·(Cp−Ce)
dQ/dt = Cp
```

**V — не объём крови.** Системная камера приближает распределение по организму. Ce — не дополнительная масса и не измеренная концентрация ткани; отток из A в Ce не вводится. Это стандартная математическая конструкция места эффекта с принятой пропорцией в равновесии 1. Полувремя Ce 5 мин — гипотеза разработчика. Базовая модель без поля `perfusion` не содержит региональной перфузии. Ни один режим пока не включает белкового связывания, отдельного свободного кофеина или измеренного транспорта через ГЭБ.

Начальные параметры: 70 кг, Vd=0.7 л/кг, F=1, полувремя всасывания 7.5 мин, элиминации 5 ч. Это выбранный сравнительный набор, не совместная подгонка к одному исследованию. [Blanchard & Sawers 1983](https://pubmed.ncbi.nlm.nih.gov/6832208/) подтверждают быструю и почти полную биодоступность, с вариабельным выведением (проверена аннотация). [Lelo et al. 1986](https://bpspubs.onlinelibrary.wiley.com/doi/10.1111/j.1365-2125.1986.tb05246.x) дают контекст для кажущегося распределения у здоровых мужчин (проверена аннотация издателя). Конкретные 7.5 мин и 5 ч остаются допущениями, а не средними с указанной ошибкой. Изменение t½ моделирует чувствительность; автоматических множителей для курения, беременности, генотипа или лекарств нет.

Элиминация объединяет убыль родительского кофеина. E не обозначает массу мочи, параксантина или общую массу метаболитов; их концентрации и эффекты неизвестны. Образование активных метаболитов, толерантность, циркадные ритмы и нелинейная кинетика высоких доз не моделируются.

## Численный метод и проверки

Фиксированный RK4, шаг 0.05 мин; запись каждые 0.5 мин. При включённой перфузии первые 5 мин записываются через 0.05 мин. События лежат на сетке 0.5 мин и применяются до записи соответствующего времени. Нет скрытого округления произвольных событий: неверная сетка отвергается. Баланс G+A+E+L = сумма уже принятых доз проверяется при записи; Ce и Q в него не входят. Результаты не обрезаются к нулю.

Техническая область: масса 30–200 кг, Vd 0.4–1 л/кг, F 0–1, полувремя всасывания и Ce 0.5–60 мин, элиминации 1–20 ч; горизонт 1–48 ч, до 32 приёмов по 0–500 мг, суммарно до 2000 мг. Это вычислительные ограничения, не границы клинической безопасности. Не все комбинации биологически правдоподобны.

Независимый аналитический эталон для одиночной дозы:

```
Cp(t) = F·D·ka/[V(ka−ke)] · (exp(−ke·t)−exp(−ka·t))
Tmax = ln(ka/ke)/(ka−ke)
AUC(0,∞) = F·D/(V·ke)
```

Тесты сравнивают Cp и конечную AUC с аналитическим решением, терминальное полувыведение, баланс массы, отсутствие эффекта до события, линейную суперпозицию повторных доз, нулевую дозу, совпавшие ka=ke=kb (решение с t·exp и t²·exp), быстрые крайние параметры при делении шага пополам. Это численная проверка; экспериментальные концентрации конкретного человека не воспроизведены.

## Отдельные PET-оценки

[Elmenhorst et al. 2012](https://jnm.snmjournals.org/content/53/11/1723): `O_A1 = Cp/(12.5+Cp)`. Использована оценка C50 из Results; **не Kd**. Проверен индексированный полный текст; прямое открытие издателя вернуло HTTP 403. Общая модель занятости A1 по Lassen не содержит плотностей по областям. Применение общей оценки к 47 мешам серого вещества — отображение одного модельного числа; различия регионального действия не измерены. Для остальных тканей значение отсутствует. Выше ~9 мг/л указана экстраполяция.

[Ishibashi et al. 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9306703/): `O_A2A = 0.811·Cp/(2.2+Cp)`. Полный текст проверен. Это стриатальная PET-модель пяти пациентов с болезнью Паркинсона на терапии; перенос на здорового взрослого не валидирован. В атласе область отображения ограничена хвостатым ядром и скорлупой. За пределами ~4.36–8.94 мг/л — экстраполяция. Общую плазму приравниваем к сыворотке как отдельное допущение.

Обе функции используют **Cp, не Ce**. Оценки квазиравновесные: динамика связывания и применимость к быстро изменяющейся пероральной PK не проверены. A1 и A2A нельзя усреднять, трактовать как активацию, проценты бодрости или функциональный ответ. Эндогенный аденозин присутствует на качественной карте; его концентрация и конкурентная динамика не рассчитаны.

## Опциональная гипотеза E/I

По умолчанию выключена. Снимок выбранного времени PK замораживает Ce. Дважды рассчитывается сохранённый протокол сети: без изменения и с добавочным постоянным входом в E-популяции:

```
P_extra(region) = g1 · fit_A1(Ce)
               + [caudate/putamen] · g2 · fit_A2A(Ce)
```

g1=2, g2=0 — выбранные коэффициенты, не измерение и не доказанный знак влияния. Здесь PET-функции дополнительно перенесены с Cp на Ce; это часть гипотезы. Выбор g=0 или Ce=0 даёт одинаковые нейронные трассы. Сеть остаётся illustrative (`wilson_cowan_delayed_rate_v1`); её связи не являются человеческим коннектомом. Параметры, источник сети и полный протокол входят в сценарий кофеина.

Сравнение ведётся на одной шкале нейронного времени в мс; PK имеет отдельную шкалу в часах/минутах. ΔE — разность состояний двух расчётов, не изменение BOLD, частота спайков или поведенческий прогноз. Изменение PK, времени или коэффициентов аннулирует прежний снимок. Это сравнение условных нейронных опытов при разных уровнях экспозиции, не многочасовое интегрирование спайковой сети.

## Воспроизведение и источники

```
./scripts/cargo-local run -p neuro-cli -- new-caffeine caffeine.json
./scripts/cargo-local run -p neuro-cli -- caffeine caffeine.json --csv pk.csv --json report.json
# После явного включения neural_hypothesis.enabled в сценарии:
./scripts/cargo-local run -p neuro-cli -- caffeine caffeine.json --network-at-min 60 --json report.json
```

JSON отчёта хранит полную конфигурацию и provenance_id; CSV — всю PK-трассу с единицами и версиями. Проект кофеина дополнительно хранит сцену мозга. Открытие пересчитывает PK и возвращает время к 0 на паузе; нейронный снимок не является продолжением интегратора. Внешние запросы во время расчёта не нужны. Карта, источники и оговорки встроены в бинарник; `data/caffeine-model.json` включён в `.app/Resources/licenses`.

## Региональное расширение

Поле `perfusion` включает [региональную доставку](perfusion-model.md) с отдельным model_id/revision/provenance. Отсутствующее поле сохраняет общий Ce и прежние входы E/I. В новых сценариях и `scenarios/caffeine-perfusion.json` расширение включено; `scenarios/caffeine.json` остаётся контрольным старым примером. PET-слои A1/A2A продолжают использовать общую Cp и прежний контекст. Локальная Ct не превращает их в измеренную карту плотности.

В сравнении E/I `driver_basis` явно задаёт `regional_tissue_ct` либо `common_effect_site_ce`, `regional_drivers_mg_l` хранит все фактически использованные местные концентрации. `driver_brain_proxy_mg_l` заполнен только при использовании общего Ce.
