# Форматы данных и совместимость

[Индекс](README.md) · [CLI](cli.md) · [Архитектура](architecture.md)

## Что сохраняется

Сценарий задаёт вычисление; сцена — только отображение анатомии; проект объединяет сцену и сценарий; отчёт содержит вычисленные результаты. Экспортированный JSON трассы не является автоматически входным проектом. Для воспроизведения используйте исходный сценарий/проект, а не переименованный отчёт.

| Документ | Опознаватель | Пример / загрузка |
|---|---|---|
| A/B | `model_id=competitive_binding_equilibrium_v1` | [competition.json](../scenarios/competition.json), `run` |
| Black–Leff | `model_id=operational_agonism_n1_v1` | [response.json](../scenarios/response.json), `run` |
| Анатомическая сцена | `document_kind=brain_scene` | [brain.json](../scenes/brain.json), GUI |
| Сеть | `document_kind=brain_network` | [brain-network.json](../scenarios/brain-network.json), `simulate` |
| Сетевой проект | `document_kind=brain_project` | GUI, поля `scene` и `network`, `simulate` |
| Кофеин | `document_kind=caffeine_scenario` | [caffeine.json](../scenarios/caffeine.json), `caffeine` |
| Кофеиновый проект | `document_kind=caffeine_project` | GUI, `scene` и `scenario`, `caffeine` |
| Полный контур | `document_kind=circulation_scenario` | [историческая ревизия 1](../scenarios/purine-circulation.json), `circulation` |
| Циркуляционный проект | `document_kind=circulation_project` | GUI, `scene` и `scenario`, `circulation` |
| Оцифрованные кривые | `format_version`, `id`, `species`, `matrix`, `curves`, `gaps` | [purine-pk-curves.json](../data/purine-pk-curves.json), `fit-purine-curves` |

Схема определяется serde-типами и валидаторами `neuro-domain`, а не отдельным JSON Schema. Используйте `new*`/сохранение GUI как основу; новые неизвестные поля в строгих научных типах отклоняются.

## Версии

`format_version=1` относится к формату документа, `model_revision` — к математике/правилам модели. Версия атласа и provenance записываются отдельно. Они не являются версией приложения `0.1.0`.

| Модель | Поддерживаемая ревизия / соглашение |
|---|---|
| `competitive_binding_equilibrium_v1` | 1 |
| `operational_agonism_n1_v1` | 1 |
| `wilson_cowan_delayed_rate_v1` | 1 |
| `caffeine_oral_pk_pet_v1` | 1 |
| `caffeine_regional_perfusion_v1` | 1, опциональное расширение кофеина / региональная конфигурация |
| `purine_closed_circulation_v1` | 1…4; новый общий сценарий создаётся как 4 |
| `purine_illustrative_drive_v1` | 1; опциональная учебная гипотеза |
| `oral_plasma_curve_fit_v1` | 1; отчёт отдельного подбора |

У полного контура ревизия 1 ограничивает парный профиль приёмом в t=0; 2 допускает общий отложенный момент; 3 уточняет референсную PK/всасывание; 4 добавляет 1…4 ступени и необязательное периферическое распределение. В ревизиях 1…3 новые транспортные поля имеют нейтральные значения. Старые сериализованные параметры не обновляются автоматически.

## Ключи и единицы

- Области связаны по FMA ID; позиции в массиве и отображаемые названия не заменяют стабильный ID.
- В полном контуре вещества и массивы параметров упорядочены **C/M/T**: `caffeine`, `methylliberine`, `theacrine`. Доза дополнительно хранит явный `substance`.
- PK-время — минуты, длительность сети — миллисекунды; V — л, CL/Qd — л/ч, концентрации — мг/л, массы — мг.
- CBF — мл/(100 г·мин); потоки вещества — мг/мин. При интегрировании CL переводится из л/ч в л/мин.
- В наборе оцифровки ось концентрации задана в ng/mL; наблюдения конвертируются в мг/л делением на 1000. `ka` отчёта подбора задана в ч⁻¹, в контуре используется полувремя одной ступени в минутах.
- E/I, входы и коэффициенты учебной модели безразмерны, если явно не указано иное. `S` имеет единицы мг/л.

## Полный контур, ревизия 4

`parameters[0..2]` содержит V/F, CL/F, полувремя одной ступени всасывания, `absorption_stages`, `peripheral_volume_l`, `distribution_clearance_l_h`, тканевый Kp и обмен. Необязательные нейтральные поля могут отсутствовать при сериализации: одна ступень, нулевые Vp/Qd.

`doses` — список `{substance, time_min, amount_mg}`. Текущие технические пределы: до 32 приёмов, 0…500 мг на строку, сумма до 2000 мг, горизонт 5…2880 мин, время на сетке 0,5 мин. Они не задают безопасные дозировки. Остальные пределы проверяет `CirculationScenario::validate`.

`beds` задаёт региональный транспорт и сосудистую гипотезу. `calibration_curve_ids` сохраняет происхождение исследовательских коэффициентов, но не делает иной состав/дозу измеренным протоколом. Для этих протоколов `interactions=false`, чтобы не применить поправки смеси повторно. `neural_hypothesis` не обязана присутствовать; отсутствие не означает измеренный нулевой эффект.

## Оцифровка и отчёт подбора

Каждая кривая содержит источник/рисунок, SHA-256 исходного изображения, статус проверки, состав, n, линейную ось времени, логарифмическую ось концентрации и пиксельные точки. Для известного номинального времени используется `time_min`; иначе оно восстанавливается из пикселей с погрешностью чтения. `exclude` объясняет исключение, `upper_limit_ng_ml` задаёт цензурирование.

Отчёт хранит все кандидаты, выбранные параметры, прогнозы, ошибки, диагностику при исключении точек и пробелы. `jackknife_min/max` не являются 95% доверительными интервалами. Файл [purine-pk-fits.json](../data/purine-pk-fits.json) встроен в GUI; при смене данных/алгоритма его следует пересчитать вместе с проверками. [Методика](full-pk-calibration.md).

## CSV

| Экспорт | Строка | Основные поля |
|---|---|---|
| Анатомия | область | ID, имена, группа, слой, сторона; без рассчитанной активности |
| A/B и ответ | текущая точка / точка кривой | версии, входы, занятость/ответ |
| Сеть | время × популяционная область | `time_ms`, `region_id`, `e`, `i`, шаг и версии |
| Кофеин | время | системная PK, PET, AUC и массы |
| Перфузия кофеина | время × область | Ca/Ct, CBF, диагностическая масса и накопленные потоки |
| Полный контур | время × вещество | введено, ЖКТ, rest, Cp, мозг, устранено, возврат, AUC, ошибка баланса |
| Регионы полного контура | время × область × вещество | Ccap/Ct/Cv, массы, CBF, текущие/накопленные потоки |
| Подбор | исходная оцифрованная точка | наблюдение, прогноз, остаток, погрешность, исключение, верхний предел |

Точный заголовок записывается первой строкой; не предполагайте один формат для всех команд. CSV использует десятичную точку и полную round-trip точность f64. Общий CSV ревизии 4 дополнен `peripheral_mg`, старые ревизии сохраняют прежний набор столбцов.

Для полного контура:

```text
введено = ЖКТ + rest_mg + peripheral_mg + brain_mg + eliminated_mg
```

Не прибавляйте региональные массы мозга ещё раз поверх `brain_mg`. Для прежней односторонней перфузии региональная масса диагностическая и в эту формулу не переносится.

## Проверка и файловая безопасность

Импорт через `load` ограничивает входной JSON 1 МиБ; массивы и числовые диапазоны ограничены дополнительно. NaN/∞ в JSON не допускаются, доменная проверка требует конечность чисел. Геометрические декодеры проверяют сигнатуры, количество, индексы, ID и лишние байты.

Сохранение использует соседний уникальный временный файл, `sync_all` и `rename`. Это рассчитано на локальную файловую систему, не является совместным редактированием или распределённой транзакцией. Родительский каталог должен существовать. Не путайте защиту входного файла с запретом замены произвольного выходного отчёта.

Для публикации результата сохраните сценарий, commit SHA, Cargo.lock, `rustc --version`, ОС/архитектуру, команду, CSV/JSON, версию/идентификатор набора данных и исходные права. Побайтное равенство GUI/CLI проверяется в одной среде; на иной CPU сравнивайте с объявленным численным допуском.
