# Документация NeuroLab

[На главную](../README.md)

## Проверки

[verification.md](verification.md) — основной журнал: среды, даты, актуальные дополнения и известные технические ограничения. В нём сохранены исторические результаты; более старое число тестов не означает текущее число тестов.

Специализированные записи: [перфузия](perfusion-verification.md), [полный контур](circulation-verification.md), [единый запуск](simulation-launcher-verification.md), [плазменные ориентиры](pk-reference-review.md), [подбор кривых](full-pk-calibration.md).

Документация пользователя, CLI и архитектура описывают текущее поведение. Исторические разделы с конкретной датой/ревизией описывают именно тот этап. Численная проверка, подбор параметров и независимая биологическая валидация — разные статусы.
