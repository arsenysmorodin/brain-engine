# Анатомическая основа мозга

Атлас `bodyparts3d_brain_4.0`, ревизия 1. 58 структур с FMA ID, 63 меша, 204507 вершин, 370316 треугольников. Вид: Homo sapiens, модель взрослого мужчины. Это геометрическая основа будущей симуляции: параметры динамики, наблюдения и межрегиональные связи пока не заданы.

## Источник и права

Официальный [BodyParts3D / LSDB Archive](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html), версия данных 4.0, архив IS-A OBJ с 99% сокращением полигонов. [Условия источника](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html) обновлены 27.02.2025: **CC BY 4.0**, а не старая CC BY-SA 2.1 Japan из прежних зеркал. Источник, таблицы названий/составов и актуальные условия проверены 24.10.2026. Требуемая атрибуция: BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International. Публикация о наборе: Mitsuhashi et al., DOI 10.1093/nar/gkn613, PMID 18835852; содержательные функциональные утверждения из неё не импортировались.

`data/brain-atlas.json` хранит имена на русском/английском, FMA ID, сторону, тип ткани/полости, группу интерфейса, соответствующие файлы источника, CRC32 исходных OBJ и происхождение. `assets/brain/source-mapping.json` — выбранное соответствие FMA → исходные меши. Метаданные и производные геометрические ресурсы имеют CC BY 4.0; собственный Rust-код остаётся MIT. Notice: `assets/brain/LICENSE-BodyParts3D.txt`.

## Область применимости

Группы слева — редакционная навигация по крупным анатомическим разделам, не функциональная парцелляция и не карта нейронных сетей. Геометрия низкополигональная, набор неполон; индивидуальная вариабельность, микроархитектура и границы клеточных популяций не представлены. Координаты исходного BodyParts3D не зарегистрированы в MNI. Из формы, соседства или размера объектов не выводятся связи, сила связи или активность. Желудочки — полости, белое вещество — отдельный тип: их нельзя автоматически считать нейронными популяциями.

## Форматы и воспроизводимость

`bodyparts3d.bin`: сигнатура NBRN0001, число мешей u32 LE; для каждого — длина UTF-8 ID u32, ID, число вершин u32, число индексов u32, xyz f32 LE и индексы u32 LE. Загрузчик проверяет сигнатуру, размеры по манифесту, ID, конечность координат, индексы и отсутствие лишних байтов. Исходные OBJ триангулированы и округлены до f32; дополнительные сглаживание/децимация при импорте не выполняются.

SHA-256 геометрии: `a4ed906a1eb5dc9c87ae5e11aab72909f3cd504d21270c225ad9fefe6014f86f`.
SHA-256 манифеста: `ea2241b3aa71e454f60d66091e59a0860baec5a610189fcdf3859eb164fe6f53`.

Повторный импорт — Rust example `import_brain` в neuro-domain. В `.local/brain-source/` нужны `isa-parts.tsv` и `isa-elements.tsv` из `https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/isa_parts_list_e.txt` и `isa_element_parts.txt`; `isa-tail.bin` — последние 524288 байт `isa_BP3D_4.0_obj_99.zip` (curl --range -524288). Проверенный размер архива 142903898 байт. Импортёр скачивает диапазон 60069314…69653076 (около 9.6 МБ), извлекает только выбранные OBJ и проверяет CRC каждого файла. Полный архив тела не нужен. Команда из корня: `./scripts/cargo-local run -p neuro-domain --example import_brain --offline`; первому импорту требуется сеть для curl, дальнейший использует кеш. Детерминированность проверяется SHA-256 файлов выше.

Сцена `document_kind=brain_scene` хранит версию атласа, выбранную структуру, камеру, видимость слоёв/сторон, изоляцию, скрытые области, цветовую схему и раздвижение. Это сохранение анатомического рабочего пространства. Данные существующих численных экспериментов сохраняются отдельно.

## Подключение будущей симуляции

Стабильный ключ области — FMA ID; меши — визуальное представление области и не задают число клеток. Будущий вычислительный модуль должен отдельно указать модель популяции, единицы, параметры и источники, а для связей — направление, веса/задержки и происхождение. Неподключённая активность неизвестна и не записывается нулём. `neuro-cli atlas --csv regions.csv` экспортирует инвентарь с `activity_status=not_configured`.
