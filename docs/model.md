# Равновесное конкурентное связывание, revision 1

Отдельный модуль функционального ответа описан в [response-model.md](response-model.md). Формула и ревизия связывания не изменены.

Динамика популяций и задержанных межрегиональных связей описана в [network-model.md](network-model.md). Этот модуль не получает занятость рецепторов как вход без отдельной модели сопряжения.

Идентификатор: `competitive_binding_equilibrium_v1`. CPU, `f64`, детерминированный расчёт без случайных чисел. Входные данные **illustrative**, без связи с измеренными параметрами кофеина.

## Определения

`R + A ⇌ RA`, `R + B ⇌ RB`. Входы `a = [A]free / Kd_A`, `b = [B]free / Kd_B` безразмерны. Пользователь задаёт отношения; концентрации и Kd по отдельности не задаются и не восстанавливаются.

При равновесии `[RA]/[R] = a`, `[RB]/[R] = b`, поэтому:

```text
Z      = 1 + a + b
p_free = 1 / Z
p_A    = a / Z
p_B    = b / Z
```

Выходы — доли рецепторов в трёх взаимоисключающих состояниях. Формула следует из закона действующих масс для явно заданных допущений; это не экспериментальный результат. Время отсутствует.

## Допущения

- Один тип одинаковых независимых рецепторов и один рассматриваемый сайт.
- Связывание A и B взаимоисключающее, обратимое, равновесие достигнуто.
- Свободные концентрации заданы; расход лигандов связыванием не учитывается.
- Однородная среда; нет кооперативности, аллостерии, интернализации, метаболизма.

## Диапазон и устойчивость

Поддерживаются `0 ≤ a,b ≤ f64::MAX` (около `1.7976931348623157e308`), включая субнормальные значения. NaN, ±∞ и отрицательные значения отклоняются до вычисления; `-0.0` эквивалентен нулю. JSON не поддерживает NaN/∞.

Вместо потенциально переполняющегося `1+a+b` вычисляются:

```text
s = max(1, a, b)
u = 1/s; v = a/s; w = b/s
d = u+v+w                 # 1 ≤ d ≤ 3, без переполнения
p = (u/d, v/d, w/d)
```

IEEE-754 округление и underflow очень малых долей допустимы: значения меньше представимого субнормального f64 могут округлиться к нулю. Это численная потеря представимости, не отсутствие вещества и не неизвестное значение в каталоге. При `a=b=f64::MAX` доли A/B близки к 0.5; свободная доля остаётся положительной. Относительная точность не гарантируется для субнормальных долей. Порядок суммирования фиксирован; для сравнения на разных CPU используйте абсолютный допуск, а не требование побитового совпадения.

## График

Ось X: фактическое `a`, расположение `ln(1+a)`; ноль включён и не заменён epsilon. Ось Y: `p_A`, от 0 до 1. Первая кривая — фиксированное текущее b, вторая — b=0. Точка — текущие a,b. Сетка по X равномерна в `ln(1+a)`, подписи показывают исходные a. По умолчанию 257 точек, разрешено 2–4097; максимум a > 0 и конечен. Концевые точки задаются точно. Подсказка пересчитывается ядром. Если точка вне диапазона, это обозначено и доступна кнопка расширения диапазона. Для экстремально малых диапазонов точки могут совпадать из-за квантования f64; интерполяция линии визуальная.

Формулы кривых и текущая точка вычисляются в neuro-engine; UI лишь переводит результаты в координаты f32 для рисования. Изменения параметров не являются траекторией по времени.

## Воспроизводимость

Сценарий сохраняет format_version, model_id, model_revision, data_kind, a,b, имя и диапазон/число точек. Неизвестные версии, ревизии, модели, поля, неполные и повреждённые файлы отклоняются явно. JSON ограничен 1 МиБ. Запись через соседний временный файл + sync + rename сохраняет старую версию при ошибке записи; гарантия атомарности рассчитана на локальную файловую систему. Импорт проверяется до изменения состояния GUI.

CSV включает входы и версии; JSON-экспорт включает полный сценарий. Для полной трассировки среды сохраняйте также Cargo.lock, версию Rust и commit исходников. Изменение математики требует новой ревизии.

## Проверки и интерпретация

Тесты: нули; три доли по 1/3; аналитическое `(3,6) → (0.1,0.3,0.6)`; диапазон и нормировка; обмен лигандов; монотонность конкуренции; NaN/∞/отрицательные входы; subnormal/MAX; конечность и монотонность сетки; значения CSV; round trip сценария; CLI против общего пути GUI.

Абсолютный допуск для нормировки и симметрии в тестах — `5*f64::EPSILON`. Для большого a численные плато могут скрывать строгое убывание по b из-за округления; проверяется нестрогое убывание и отдельный случай строгого уменьшения.

Занятость не равна активации. Не моделируются выброс нейромедиаторов, настроение, внимание, активность мозга и безопасность веществ. Ki/IC50/EC50 не подставляются вместо Kd. Эта демонстрация проверена математически; она не валидирована как модель конкретной биологической системы.

## Ревизия 3 контура пуринов: плазменные ориентиры

`purine_closed_circulation_v1`, revision 3: новые референсные параметры кофеина взяты из когорты He 2017 (V/F=33.5 л, CL/F=4.1 л/ч), а скорости всасывания C/M/T привязаны к опубликованным Tmax через уравнение Бейтмана. Сохранённые ревизии 1/2 используют прежние сериализованные параметры и правила взаимодействий. Уравнения консервативного сосудистого решателя не меняются. Формула определения ka, происхождение величин, численные отклонения и ограничения описаны в [pk-reference-review.md](pk-reference-review.md). Это сверка сводных плазменных показателей, а не валидация региональной PK или нейронного действия.

## Ревизия 4 контура: перенос подобранной формы плазменной кривой

Добавлены 1…4 последовательные GI-ступени с одинаковой ka и необязательный периферический системный компартмент: `dMp/dt=Qd*(Cp-Mp/Vp)`. Центральная масса получает обратный поток; CL устраняет вещество только из центрального компартмента. В CSV ревизии 4 явно добавлен `peripheral_mg`; баланс включает эту массу и сумму всех GI-ступеней. Положительные точные парные переходы включены симметрично в Strang-разбиение. Старые ревизии 1…3 требуют одну GI-ступень и нулевое периферическое распределение, сохраняют прежний порядок операций и формат CSV.

Подобранный протокол переносится целиком для состава/доз конкретного исследования; парные поправки взаимодействий выключены, чтобы не учитывать смесь дважды. Идентификаторы кривых сохраняются в проекте. Изменённые дозы и повторные введения — экстраполяция. Центральный объём решателя по-прежнему вычитает вместимость мозговых компартментов из кажущегося V; поэтому ошибка сверки вычисляется повторно по фактической трассе полного контура, а не копируется из аналитической подгонки. Тканевые Kp/обмен и нейронная гипотеза не откалиброваны плазменными данными.
