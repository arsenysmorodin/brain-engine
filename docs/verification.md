# Фактическая проверка первой итерации

Дата: 24 октября 2026, macOS 26.6.2, Apple Silicon (`arm64`), Rust 1.99.1 (58cf8f9c3, 2026-10-13). Toolchain установлен из официального rustup локально в `.local/`. Прикладной стек — Rust; shell-скрипты только запускают Cargo и собирают `.app`.

## Сборка и автоматические проверки

Выполнены успешно с сохранённым Cargo.lock:

```sh
./scripts/cargo-local fmt --all --check
./scripts/cargo-local test --workspace --locked --offline
./scripts/cargo-local clippy --workspace --all-targets --locked --offline -- -D warnings
./scripts/cargo-local build --workspace --locked --offline
./scripts/macos-app
codesign --verify --deep --strict output/NeuroLab.app
```

**14 тестов:** 6 численных/экспортных, 2 доменных, 3 сквозных теста CLI, 3 теста приложения (общий путь расчёта и недопустимый ввод, кириллица/научные символы, перемещение карты событиями egui). Во время повторного запуска обнаружена и исправлена коллизия имён временных папок параллельных тестов: добавлен атомарный счётчик. После исправления весь набор прошёл.

Численные проверки включают a=b=0, a=b=1, аналитический случай (3,6), нормировку, диапазон, симметрию, уменьшение p_A при конкуренции, NaN/±∞/отрицательные значения, subnormal и f64::MAX. Проверены round trip JSON, повреждённый JSON, неизвестная версия, ошибка записи, запрет экспорта поверх входного сценария и соответствие значений CSV расчёту.

Совместимость Bevy 0.18.1 / bevy_egui 0.39.1 сначала проверена компиляцией минимального окна до построения полного UI. GUI-зависимости отсутствуют в neuro-engine и neuro-domain. Зафиксированный egui — 0.33.3.

## Запуск настоящего GUI

Приложение действительно запускалось в графическом сеансе macOS с Metal. Из filesystem sandbox GPU был недоступен; запуск с разрешённым доступом к WindowServer/Metal прошёл. Это проверка исполняемого приложения, а не только компиляция.

Автоматический smoke-run:

```sh
./target/debug/neuro-app --smoke-test output/verified
./target/debug/neuro-cli run output/verified/scenario.json \
  --csv output/verified/cli.csv --json output/verified/cli.json
cmp output/verified/gui.csv output/verified/cli.csv
```

Проверено в GUI-пути: запуск, выбор утверждения, a=3,b=6, сохранение JSON, изменение a, повторное открытие сохранённого файла, восстановление (3,6), экспорт CSV, отклонение повреждённого файла с сохранением текущего сценария в памяти, отклонение NaN. **CSV GUI и CLI совпали побайтно.**

Артефакты локальной проверки (output игнорируется Git):

- `output/verified/map.png` — карточка кофеина и интерактивная карта.
- `output/verified/source.png` — выбранная связь кофеин–A2A.
- `output/verified/experiment.png` — (3,6), доли 10%/30%/60%, обе кривые и текущая точка.
- `output/verified/corrupt-file.png` — видимая ошибка повреждённого файла.
- `output/verified/invalid-input.png` — NaN блокирует расчёт.
- `output/verified/passed.txt`, `scenario.json`, `gui.csv`, `cli.csv`, `cli.json`.

Изображения осмотрены. Исправлены обрезанный заголовок, недостаток места для графика и отсутствующие символы; добавлены Noto Sans Math / Symbols 2 и тест покрытия глифов. Проверены стандартное окно и Retina-рендеринг. На минимальном размере 1100×720 доступны прокрутка эксперимента и инспектора; отдельный систематический тест всех размеров/дисплеев не проводился.

## Проверка обычными действиями в окне

Через нативное управление macOS проверены:

1. Клик по связи кофеин–A2A: выделение и объяснение; прокрутка инспектора до DOI/PMID и статуса проверки.
2. Кнопка увеличения карты: масштаб 100% → 115%.
3. Переход в эксперимент через боковую панель; точный ввод (3,6) → 10%/30%/60%.
4. Клик по ползунку: a=40 при b=6 → около 2.13%/85.11%/12.77%, точка графика переместилась.
5. Реальная кнопка сохранения: `neuro-scenario.json` при (1,1). Затем параметры изменены на (3,6); реальная кнопка открытия восстановила (1,1) и три доли по 1/3.
6. Реальная кнопка экспорта записала `neuro-results.csv`. CLI прочитал этот сохранённый пользователем через GUI файл, экспортировал `output/verified/manual-cli.csv`; сравнение с `neuro-results.csv` прошло побайтно.

Файловый маршрут проверялся запуском `.app/Contents/MacOS/NeuroLab` из корня репозитория: оба пути находились внутри рабочей папки. Сохранение/открытие проверены через кнопки с заданным путём. Изменение пути обычным набором латиницы, вставка и Command-сочетания через инструмент автоматизации в русской раскладке срабатывали некорректно; их успешная интерактивная проверка **не заявляется**. Включена стандартная clipboard-интеграция bevy_egui; эти сочетания требуют отдельной проверки физической клавиатурой. Неподтверждённое управление не использовано как доказательство сквозного сценария.

Системный drag инструмента автоматизации не дал надёжного подтверждения перемещения; перенос на (50,50) и сброс карты проверены отдельным тестом egui по последовательности событий. Проверка живого перетаскивания трекпадом остаётся полезной.

## Известные технические ограничения

- Зависимость `block 0.1.6` выдаёт предупреждение будущей несовместимости Rust (`static` необитаемого типа); это транзитивная зависимость Metal. Сборка текущим toolchain проходит; предупреждение задокументировано, чужой код не патчился. Строгий Clippy собственного workspace прошёл.
- Metal отключает неподдерживаемый режим bindless textures и использует обычный режим; это сообщение bevy_egui, скриншоты и расчёты работают.
- Сборка dev без debug symbols, не подписанный Developer ID релиз. `.app` подписан ad hoc и проверен codesign; notarization и распространение не проверены.
- Систематические VoiceOver, смена экранов/DPI, многодневная работа, native Finder-диалоги и другие ОС не проверялись. В первой версии используются встроенные файловые диалоги с путём.
- Внешние ссылки на публикации не являются частью офлайн-пути. Проверены аннотации, не полные тексты.

Научная область применимости ограничена [моделью](model.md). Успех математических тестов не доказывает применимость к конкретному веществу или биологической системе.
