# Единый запуск и одинаковые представления веществ

25.10.2026. Native Rust/egui, без новых UI-зависимостей. Используется frontend-design: сохраняются Noto Sans, фон #11151C, поверхности #171D26, границы #313D4B, основной текст #EAF0F6. Главный запуск выделен #65DAC9; вещества сохраняют оранжевый/бирюзовый/фиолетовый цвета. Текст слева, одинаковые строки параметров вместо набора декоративных карточек.

```
NeuroLab                    [Запустить симуляцию] [файлы]
            ┌──────────────────────────────────────┐
            │ Вещество       Доза, мг   Время, мин │
            │ Метиллиберин   100        30         │
            │ + Добавить приём                     │
            │ Длительность / взаимодействия        │
            │ [Отмена]      [Запустить симуляцию]   │
            └──────────────────────────────────────┘
```

Время — минуты от начала сценария, способ — пероральный приём. Это явные подписи формы, чтобы «введение» не воспринималось как внутривенная инъекция. При запуске проверяются все строки, затем вычисляется новая трасса и включается воспроизведение с t=0. Отмена и невалидный черновик сохраняют текущий протокол и его результат. Поля формы — отдельный черновик. Повторные приёмы можно добавлять до общего ограничения 32.

Проверка плана: основной вход — одна заметная кнопка из любого раздела, а настройки PK остаются в научной панели. В форму не вынесены подробности решателя и модели E/I; это мешало бы выбрать вещество/дозу/время. Состав смеси определяется строками, а не привязан к кофеиносодержащему пресету. Отложенный общий момент дозирования поддерживается ревизией 2, старая ревизия воспроизводится прежним способом.

Кофеин, метиллиберин и теакрин получают одинаковые режимы 3D/путь вещества, графики плазмы/местных концентраций/кровотока/массы/потоков и отдельное сравнение E/I. У карты есть значения на выбранном времени, выбор узлов и объяснения происхождения. Неизвестная рецепторная занятость M/T не подменяется кофеиновой PET-кривой. Учебная нейронная гипотеза имеет собственную версию, выключена изначально, сохраняет коэффициенты и сеть для воспроизведения.
