# Единый запуск и одинаковые представления веществ

25.10.2026. Native Rust/egui, без новых UI-зависимостей. Используется frontend-design: сохраняются Noto Sans, фон #11151C, поверхности #171D26, границы #313D4B, основной текст #EAF0F6. Главный запуск выделен #65DAC9; вещества сохраняют оранжевый/бирюзовый/фиолетовый цвета. Текст слева, одинаковые строки параметров вместо набора декоративных карточек.

```
NeuroLab                    [Запустить симуляцию] [файлы]
            ┌──────────────────────────────────────┐
            │ Вещество       Доза, мг   Время, мин │
            │ Метиллиберин   100        30         │
            │ + Добавить приём                     │
            │ Длительность / взаимодействия        │
            │ [Отмена]      [Запустить симуляцию]   │
            └──────────────────────────────────────┘
```

Время — минуты от начала сценария, способ — пероральный приём. Это явные подписи формы, чтобы «введение» не воспринималось как внутривенная инъекция. При запуске проверяются все строки, затем вычисляется новая трасса и включается воспроизведение с t=0. Отмена и невалидный черновик сохраняют текущий протокол и его результат. Поля формы — отдельный черновик. Повторные приёмы можно добавлять до общего ограничения 32.

Проверка плана: основной вход — одна заметная кнопка из любого раздела, а настройки PK остаются в научной панели. В форму не вынесены подробности решателя и модели E/I; это мешало бы выбрать вещество/дозу/время. Состав смеси определяется строками, а не привязан к кофеиносодержащему пресету. Отложенный общий момент дозирования поддерживается ревизией 2, старая ревизия воспроизводится прежним способом.

Кофеин, метиллиберин и теакрин получают одинаковые режимы 3D/путь вещества, графики плазмы/местных концентраций/кровотока/массы/потоков и отдельное сравнение E/I. У карты есть значения на выбранном времени, выбор узлов и объяснения происхождения. Неизвестная рецепторная занятость M/T не подменяется кофеиновой PET-кривой. Учебная нейронная гипотеза имеет собственную версию, выключена изначально, сохраняет коэффициенты и сеть для воспроизведения.

## Итоговое поведение

Для каждого вещества реализованы 3D-концентрации, общий транспортный/механистический граф с выбором узла или стрелки, графики Cp всех веществ и Cp/Ccap/Ct/Cv выбранной области, CBF, потоков, массы и E/I. PET показывается только для кофеина. Cmax/Tmax оцениваются по всей записанной трассе и подписаны как пик сценария, включая будущее; AUC относится к текущему кадру. В графике E/I отдельная миллисекундная шкала; PK-время остаётся минутным.

По умолчанию график скрыт, чтобы основным объектом оставался 3D-мозг. При выборе сравнения E/I график открывается автоматически. Компактный селектор графика содержит единицы, цветовую легенду и режим 0–5 мин; это исправляет обрезание баланса на окне высотой около 838 логических пикселей. На карте стрелка учебного входа идёт непосредственно от ткани в обход мишеней: модель не выводит g/S из PET или in vitro-рецепторных результатов. При выборе вещества, которого нет в протоколе, UI предлагает добавить приём через окно запуска.

Форма не задаёт внутривенное введение и не меняет существующий протокол до успешного расчёта. При открытии из прежнего раздела кофеина переносятся дозы, длительность, V, CL, полувремя всасывания и конфигурация перфузии, если она есть. Полный контур имеет собственные уравнения и соглашение F=1; он не заявлен как точная копия прежней односторонней PK. Старый модуль и его файлы продолжают работать отдельно.

## Работа после калибровки временных кривых

Текущий новый общий сценарий создаётся в ревизии 4. После загрузки исследовательского протокола форма наследует его системные параметры. В ней явно указано, что изменение состава/доз — экстраполяция; повторное применение парных поправок выключено. Для проверки измерений загружайте целый протокол через «Кривые исследований». Восстановление общих параметров выполняется явно в «Сверка PK», затем нужен пересчёт. [Руководство пользователя](user-guide.md), [форматы и совместимость](data-formats.md).
